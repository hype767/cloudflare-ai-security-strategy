# 클라우드플레어 AI 보안 B2B 전략

AI 시대 보안의 중요성과 AI 보안 솔루션 B2B 전략을 정리한 사이트와 60초 요약 영상입니다.

- `index.html` : 전략 사이트 (탐색적 데이터 분석, ROI 계산기 포함)
- `cloudflare_ai_security_60s.mp4` : 60초 요약 영상 (키네틱 타이포그래피 + 라인 아트 + 내레이션)
- `data/` : 분석에 쓴 시뮬레이션 데이터 (가상 기업 600곳, 실제 고객 데이터 아님)
- `build/` : 분석, 사이트, 영상 생성 스크립트

분석 수치는 모두 시뮬레이션 데이터 기준이며 전략 논의용 초안입니다.
